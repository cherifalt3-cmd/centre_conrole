# Centre de contrôle

Application web personnelle regroupant plusieurs modules (recon, OSINT, veille, kanban, suivi de conso) sous un même compte et une même base de données.

## Stack
- Backend : Django (API REST)
- Frontend : Vue
- Base de données : SQLite en local, PostgreSQL à l'hébergement

## Démarrage sur une nouvelle machine
Après un `git clone`, voir les instructions à venir pour installer les dépendances backend et frontend.
